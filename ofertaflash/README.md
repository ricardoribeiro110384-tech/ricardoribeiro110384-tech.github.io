# OfertaFlash ⚡

Gerador de artes promocionais para comércio. Projeto estático em HTML, CSS e JavaScript.

## Abrir o aplicativo

https://ricardoribeiro110384-tech.github.io/ofertaflash/

## Funcionalidades desta versão

- Cadastro, edição e exclusão de produtos, preços e fotos.
- Importação de planilhas CSV e Excel (.xlsx/.xls; Excel depende do CDN SheetJS).
- Artes para Stories, posts, TV e A4.
- Personalização de marca, telefone, cores e logotipo.
- Exportação PNG, impressão em PDF e texto de WhatsApp.
- Dados armazenados localmente no navegador (localStorage).

## Atenção

Esta é uma primeira versão sem contas, servidor ou sincronização entre dispositivos. Os dados podem ser apagados ao limpar os dados do navegador. Verifique sempre preços, fotos e validade das promoções antes de publicar.

Para começar, abra o arquivo `index.html` neste diretório.
